# WingsCraft Entertainment — Copywrk concept

A mobile-first, multi-page static website concept prepared for WingsCraft Entertainment.

## Pages
- Home (`index.html`)
- About
- Services
- Weddings
- Destinations
- Gallery
- Contact

## Mobile-first implementation
- Phone layout is the CSS baseline; larger layouts use only `min-width` enhancements.
- 44–48px touch targets and a full-screen mobile menu.
- Persistent mobile quick-action bar for Weddings + WhatsApp.
- Portrait-first wedding imagery and mobile-friendly typography/spacing.
- Native mobile scrolling; Lenis, cursor effects and parallax are desktop-only.
- Reduced-motion preference is respected.
- Safe-area padding is included for modern iPhones.

## Deploy
The project is Vercel-ready. `vercel.json` enables clean URLs, so `/weddings` maps to `weddings.html`.
